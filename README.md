# README

This repository includes a simple personal portfolio and a presentation-style version for PDF export.

## Files
- `index.html` — portfolio landing page
- `portfolio-slides.html` — presentation version in a 16:9 layout
- `styles.css` — shared styling

## Open locally
You can open either file in a browser.

For the print-ready version:
1. Open `portfolio-slides.html`
2. Press `Ctrl/Cmd + P`
3. Choose "Save as PDF"
4. Save the file as `Name_Portfolio.pdf`

## Customize
Update the following items in `index.html` and `portfolio-slides.html`:
- Your name
- Target role
- Email address
- LinkedIn profile
- GitHub profile
- Project descriptions and outcomes
